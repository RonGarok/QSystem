# Mendel

**Mendel** est le successeur de **QSystem**, un sous-système Python modulaire conçu pour améliorer l’interface et la gestion des fonctionnalités internes de QSystem.  

Le micro-logiciel **QMendel**, prévu pour faciliter la migration des fichiers et paramètres de QSystem vers Mendel, n’est pas encore disponible en raison de la complexité du projet.

---

## Installation et démarrage

1. **Téléchargez et décompressez** le fichier Mendel depuis ce dépôt GitHub.  
2. **Accédez au dossier `boot`** :  
   ```bash
   cd Mendel/boot
   ```
3. **Exécutez le script `boot.py`** pour lancer Mendel :  
   ```bash
   python boot.py
   ```
4. *(À venir)* Un **créateur de raccourcis** sera intégré pour placer Mendel directement sur le bureau.

> Note : Mendel ne nécessite pas d’installation complexe, il suffit de décompresser le dossier et d’exécuter `boot/boot.py`.

---

## Fonctionnalités principales

- **Gestion des utilisateurs** : profils et permissions configurables.  
- **Bureau amélioré** : interface graphique fluide et gestion multi-fenêtres.  
- **Gestion des mises à jour** : possibilité de redémarrage manuel ou automatique.  
- **Compatibilité QSystem** : les applications QSystem peuvent être utilisées via des modules Python adaptés.  
- **Extensible et modulable** : possibilité d’ajouter de nouvelles fonctionnalités facilement.

## Objectif du projet

Mendel vise à améliorer l’expérience utilisateur et la logique interne de QSystem tout en restant compatible avec les workflows existants.  
L’objectif est d’offrir un sous-système stable, performant et facilement extensible.
