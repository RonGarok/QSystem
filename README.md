# 🚀 QSystem évolue vers Mendel

Une nouvelle adaptation de **QSystem** arrive : **Mendel**  
Plus graphique, plus logique, et avec de nombreuses améliorations !

---

## 🔧 Mise à jour manuelle

La transition vers Mendel nécessite une mise à jour manuelle :

1. **Importer la branche `Mendel`** dès qu'elle sera disponible.
2. Installer le **micro-logiciel `QMendel`**.

---

## 🧠 Que fait QMendel ?

Le micro-logiciel `QMendel` permet :

- 🔄 De **modifier la structure** de votre QSystem pour l’adapter à Mendel.
- 🧬 De **remplacer le code** de QSystem par celui de Mendel.

---
